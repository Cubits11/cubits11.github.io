Research framework · Python · MIT · 2025 — present

CC-Framework

Evidence-bound AI assurance for composed guardrails. Stack two safety filters and their failures correlate in ways point estimates hide; CC-Framework computes Fréchet–Hoeffding bounds on stacked-system failure that stay honest about unknown dependence — then wraps every result in claim envelopes, evidence roles, Merkle-logged receipts, and decay semantics, so the evidence can never quietly say more than it knows.

02

The five-card discipline

Claim

What I say the system does. Named first, in writing.

Falsifier

The observation that would end the claim. If none exists, neither does the claim.

Control

The comparison that could embarrass it — run on purpose.

Non-claim

What this evidence will never support, stated before anyone asks.

Result

Empty until the world answers.

Inconclusive — awaiting result

Lock the first four before the result slot fills, then let the result disagree. A story can start a question. It cannot finish an answer. This page plays by the same rules: claims link to public evidence where it exists — and say so plainly where it doesn’t.
