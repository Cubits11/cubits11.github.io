The next epistemic frontier

Declare the measurement before you calculate it.

A joint number is not one thing. This workbench makes you name the system, population, event, and observation mode before it will emit a result.

It computes a static all-miss result only when every stated guard saw every stated item. For a deployed route or an adaptive attack, it records the missing protocol fields and refuses to launder those questions into a static score.

Runs in this browser

Nothing entered here is sent to this site, a vendor, or an analytics service. The output is a draft disclosure packet for your own review — not a benchmark submission, safety certificate, or claim about a real system.

The study contract this enforces

      
    

    
A first real study should preserve enough structure to distinguish what was actually measured from what remains hypothetical. The preflight makes the first layer executable; the next layers are intentionally more demanding.

    

      
A · SUT
Freeze the workflow
Name components, versions, policy/configuration, shared dependencies, and route semantics. A changed configuration is a different system under test.

      
B · Mode
Keep observation modes apart
Mark static full exposure, an actual deployed route, replay/ablation, or adaptive holdout. Do not render one as evidence for another.

      
C · Trace
Retain route and terminal facts
For a route, retain stage sequence, intervention, missingness, and terminal outcome. A blocked input is not an observation for a later stage.

      
D · Revision
Make correction additive
Bind protocol, data manifest, runner, and report. Release a linked revision with reason rather than silently rewriting an evidentiary record.

    

    
Research basis This architecture follows a system-under-test approach, keeps conditions similar to the claimed deployment visible, and treats routing/gating as measurement semantics rather than decoration. It is a protocol aid, not an adopted standard.
