# worldspace/ — the public observatory of compatible worlds

`/worldspace/` is one interactive proof: two guardrail scores that never move
while the number of items both guards miss runs the whole interval the scores
leave open, then the space of worlds that interval names, then the one point a
single assumption selects, then a route to an executable reproduction of the
same interval. Experiment E4 in the record's ledger (`LEDGER.md`).

It is not a film and it is not decoration. Its changed variable, relative to
the films and Fig. 02, is that the visitor **produces** the contradiction:
they predict, then move the misses themselves.

```text
worldspace/
  manifest.yaml     every string, fact binding, visible-object meaning, state,
                    route, non-claim, falsifier, critical screenshot and the
                    frozen cold-test protocol — the single source
  index.html        GENERATED by scripts/generate_worldspace.py — do not edit
  worldspace.js     the runtime: counts rings on discs, indexes the registered
                    world, draws; computes no probability, stores nothing,
                    sends nothing, draws no random number
  qa/               screenshots of every critical state × viewport × motion
                    setting, the 1200×630 poster, and receipt.json (input
                    hashes, assertions, performance, determinism)
  RESEARCH.md       research-derived design hypotheses, kept apart from facts
  LEDGER.md         the experiment: prediction, falsifiers, concepts killed,
                    observations from the pixel passes, what remains untested
```

## Laws it obeys

- **Binding.** Every number the page can show is derived from
  `films/data/facts.json` (itself derived from `claims.yaml` under
  `bind_facts.py --check`) by the generator, which asserts every world against
  the registered endpoint witnesses before writing. The runtime indexes; it
  does not compute a probability.
- **Truth contract.** Every visible object has a status — REGISTRY, PROVED,
  DERIVED, CONSTRUCTED, ILLUSTRATIVE, OBSERVED — in `manifest.yaml → objects`,
  and the stage's ledger line names the status of what is on screen in every
  act. The example is constructed and says so in every state.
- **Motion.** Movement is licensed only when it carries information: the
  overlap changes, the field opens, the assumption collapses the field. Under
  `prefers-reduced-motion` every transition is an immediate state change with
  the same information.
- **No dependence.** No framework, no fonts beyond the site's own, no image on
  load, no third-party request, no storage, no analytics. The static proof
  (two witnessed worlds and the axis) is in the HTML for JavaScript-off
  readers, and the runtime halts visibly rather than draw a world the registry
  does not license.

## Verify

```bash
python3 scripts/generate_worldspace.py --check   # page = f(manifest, facts, experiments)
python3 scripts/verify_worldspace.py             # bindings, worlds, constructions, text, routes, hygiene, static proof, QA receipt
```

Both run in `scripts/verification_manifest.py`, so a registry edit that
changes a number the instrument shows, a missing string, a dead route, or a
stale capture fails the build.

## Capture (local; Chrome + the render venv)

```bash
~/.venvs/cubits-films/bin/python scripts/worldspace_qa.py
```

Drives the page through real input at every declared viewport with and without
reduced motion, a keyboard-only pass, a light-theme pass, two runs for
determinism, a performance measurement over the local server, and the poster.
Re-run after any change to the page, the runtime or the manifest, then look at
the pixels before committing.

## What it is not

A deployed instrument proves availability. It does not prove that anyone
understood it. Understanding is measured by the frozen cold test in
`manifest.yaml`; independent checking is recorded, if it ever happens, in
`distribution/outcomes.yaml` — never here.
